# Plan：Web 管理台 Fluent 2 完全重写

**状态**：DONE  
**完成日期**：2026-09-20  
**版本**：v1.0  
**回归测试结论**：前端 TypeScript 校验与生产构建全绿（产出静态包）；Playwright 12 条 E2E 自动化测试全绿（无头 Chrome 12 passed in 13.2s）；后端 pytest 209 条测试全绿（209 passed in 33.60s）；全站无旧调色板遗留，零行为回归。

---

## 1. 背景与目标

Capsa Studio 当前前端为 shadcn 风格的扁平 zinc 面板：顶部标题栏 + 一行文字 Tab + 平铺内容，组件间只靠 1px 边框区分层级，缺少深度与材质表达。本次按 Fluent 2 设计系统对整个前端做**完全重写**（含布局），在保持既有 REST 契约、鉴权链路与交互能力不变的前提下交付新视觉与信息架构。

目标：

- **布局重构**：顶部 Tab 改为侧栏导航 + 标题栏（Command Bar）的 App Shell，工作台采用主从双栏。
- **材质分层**：以 Layer 0–3 建立可辨识的物理层级——Mica 画布、Acrylic 框架层（半透明 + 模糊 + 1px 高光边框）、Depth 4/8 内容卡、Depth 16 模态层。
- **令牌化**：颜色、排版、圆角、阴影、动效以语义令牌承载，浅色 / 深色两套配对值经根节点属性运行时切换。
- **零行为回归**：所有既有能力（登录、检索、新建/编辑/删除/恢复、分类与凭据管理、时效复核）与错误处理语义逐条保留。

非目标：不改动 Python 侧任何接口；不新增业务能力；不引入第三方 UI 组件库。

## 3. 架构决策

| 决策项 | 选择 | 理由 | 替代方案（为何不选） |
|--------|------|------|----------------------|
| 组件来源 | 以 Tailwind 表达 Fluent 令牌的自建原语 | 与既有技术栈同源，样式只有一套；个人 VPS 工具优先轻量 | 引入 Fluent UI React v9 或 shadcn/ui（前者与既有 Tailwind 并存形成两套样式系统并显著增大产物，后者需再叠一层风格注入） |
| 材质实现 | 复用既有 `backdrop-blur` + 半透明背景 + 1px 高光边框表达 Acrylic/Mica | 零新依赖，纯 CSS 即可达成 | 引入材质组件库（无收益） |
| 主题机制 | CSS 变量承载语义令牌，根节点属性切换 | 令牌是单一事实来源，切换无需重渲染 | 直接散写 Tailwind 色阶（深浅色无法统一替换） |
| 模态原语 | 原生 `<dialog>` + `showModal()` | 焦点约束、Esc 关闭与背景 inert 由平台提供，组件层不承担 DOM 逻辑 | 手写 Focus Trap（纯 React 下易因渲染时序与虚拟键盘产生次生问题） |
| E2E 类名断言的处置 | 把唯一一处 CSS 类名断言改为语义断言（`aria-invalid`） | 原断言把 Tailwind 类名当契约，与令牌化后的深色配色互斥；语义断言强度不降且不再耦合实现细节 | 保留 `text-red-600` 字面类（深色模式对比度不足）或删除该断言（削弱回归保障） |
| 图标 | 复用已安装的 lucide-react | 已具备线性图标集，风格与 Fluent 接近 | 新增图标依赖 |
| 校验边界 | 以既有 E2E 用例的可访问性语义（角色 + 名称 + 文本）为不可破坏契约，仅保留一处经审阅批准的语义化替换 | 重写必须可回归验证；语义契约同时是无障碍基线 | 重写用例以适配新组件树（等于取消回归保障），或保留把 Tailwind 类名当契约的断言 |

## 4. 风险清单

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 重写后既有 E2E 用例大面积失败 | 🔴 高 | 把 12 条用例的语义契约逐条写入 Tasks 验收标准；失败按契约修正组件，不放宽用例。唯一获准的用例改动（`text-red-600` → `aria-invalid`）在 Tasks 共同前置中显式声明 |
| 侧栏布局挤压窄屏内容 | 🟡 中 | Phase 1 即定义折叠/抽屉式导航，Phase 4 专项验证 375px |
| 深色模式下对比度不足 | 🟡 中 | 令牌层只使用 Fluent 官方深浅配对值，Phase 4 逐页目视核对 |
| 手工视觉验证依赖浏览器实例（有头实例不可用，9222 无响应） | 🟢 低 | 全部浏览器验证走 Playwright 无头模式：已实测无头启动系统 Chrome 成功，`boundingBox()` 量测与截图在无头下同样有效；关键页面截图输出到临时目录自查（不提交） |
