### 全局备注：
1. 个人项目非商业，在个人PC/个人VPS部署使用，避免不需要的冗余设计
2. 遵循简洁、强逻辑的模块化架构，和简洁明了的代码设计
3. 优秀、稳固的可拓展架构是第一关键，轻量和轻占用是第二关键
4. 开发环境（Linux x86_64）：Go 编译与测试，本机禁止全量构建 Windows 产物；Windows 产物构建与发布验收由云端 CI 负责
5. 测试遵循最小占用（内存/性能/储存），不缓存/不保留任何一次性构建产物
6. 浏览器操作请连接9222端口已开启的用户准备的实例
7. Git 的 commit 具体描述使用中文提交：Commit描述开头使用标准的英文 Conventional Commits 类型前缀，后方详细描述使用中文。

### 项目备注：

1. 项目名称为 Capsa，一个部署在个人 VPS 上、以 MCP 协议向 Agent 提供分组隔离与分级披露长期记忆读写，并附带全权限单管理员 Web 管理台的私人记忆服务
2. 当前项目最终会被通过docker compose部署到个人VPS中，便于远程访问和查看。
