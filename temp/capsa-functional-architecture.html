当前已提供能力（IN SCOPE）

受控共享与确定性治理

  • 按分类（Group）隔离读写边界，支持单分组精细授权与全库通配授权
  • 三级渐进披露（检索元数据 → 预览摘要 → 分页精读正文），控制上下文开销

  • 记忆置顶加权与到期复核时间（review_at）自动降权及延期治理
  • 强制填写原因的软删除回收站机制，仅允许管理员从 Web 或 CLI 恢复
  • 在线签发单次明文披露凭据、即时吊销、已吊销凭据物理清理与防自锁
  • 在线一致性热备快照生成、14 天过期轮转清理与离线快照覆盖回灌
当前明确不提供（EXPLICIT NON-GOALS）

刻意收敛的功能禁区

  • 不做向量语义检索与 Embedding：无近似向量召回，仅依赖字面与二字组分词匹配
  • 不做对话自动抽取写入：记忆新建与更新均需由 Agent 显式整理字段后调用工具
  • 不做多租户与多角色 RBAC：无独立用户表、无团队协作、无细粒度管理角色拆分
  • 不做 Cookie / Session 会话：无账密登录或 OAuth，Web 端凭据仅驻留标签页 sessionStorage
  • Web 与 CLI 不做正文全文检索：正文匹配仅作为 MCP 检索显式开启的兜底选项
  • 分类标识创建后不可重命名：slug 作为记忆外键一旦建立即永久锁定，不可迁移或合并分类
  • 回收站条目无物理清空入口：软删除记忆可恢复，但系统未开放单条或批量永久销毁能力
  • 无内置异地对象存储同步：热备仅落地本地挂载卷，异地容灾依赖外部宿主机任务

领域实体与容量契约

全部业务功能围绕「分类」「记忆条目」「访问凭据」三个核心实体展开，所有文本写入实行严格定长拒写策略，不做静默截断。

初始化默认预置四个标准分类：proj（项目）、study（学习）、life（生活）、track（追踪）。

03

鉴权接入与三态隔离

支持标准请求头与 URL 查询参数双路接入；通过四级权限求值阶梯与单条记忆三态裁决，阻断未授权分类探测。

防侧信道原则：未授权方即使猜中记忆 ID，也无法从错误文案中得知该记忆属于哪个分类，在 Web 端甚至无法区分「不存在」「已软删」与「无权访问」。

凭据传递优先级与四级权限求值阶梯

CREDENTIAL INGRESS & PERMISSION RESOLUTION
阶段 A · 边界凭据提取规则

请求头绝对优先，查询参数按需代客注入

  • 第一权威（HTTP Header）：只要请求携带 Authorization 头，系统严格以该请求头为唯一凭据来源；即使头内令牌错误或为空，也绝不回退读取 URL 参数。
  • 兼容通道（URL Query）：仅当完全未携带 Authorization 头时，依次检查 ?token= 与 ?access_token=。
  • 字符净化红线：查询参数值若为空白、含非 ASCII 字符或含不可打印控制字符（如换行符），边界直接忽略，交由下游自然返回 401。
  • 即时生效机制：除环境变量虚拟管理员外，每次请求均实时比对令牌哈希并校验未吊销，吊销操作零延迟生效。
阶段 B · 分类有效权限四级阶梯

显式分类规则优先于通配只读兜底

  • 优先级 1 · 通配全库读写：若 scopes["*"] == "rw"，对现有及未来新建的一切分类均返回 rw，且成为登录 Web 管理台的唯一通行证。
  • 优先级 2 · 显式分类声明：若显式配置了目标分类（如 {"proj": "rw", "study": "r"}），直接返回对应级别（可提升通配只读下的特定分类为可写）。
  • 优先级 3 · 通配全库只读：若 scopes["*"] == "r"，对其余未显式声明分类返回 r（可在 MCP 读取全库，但访问 Web 管理台仍返回 403）。
  • 优先级 4 · 默认拒绝：以上均未命中时有效权限为空，该分类在分组列表与检索中完全隐身。

管理台视图与跨通道矩阵

汇总 Capsa Studio 五大管理视图的交互边界，并横向拉通 MCP、Web 管理台与 CLI 三条通道的 21 项具体能力覆盖差异。

大改参考：筛选「通道独占能力」与「规则差异项」可直观定位目前能力不对称的模块（如分类编辑仅在 Web、正文检索仅在 MCP、热备仅在 CLI）。

Capsa Studio（Web 管理台）五大视图职责拆解

WEB CONSOLE SURFACES
VIEW 01 · 记忆工作台

双栏检索浏览与全字段编辑

左栏提供标题/摘要/标签实时检索、只看置顶开关与分类胶囊筛选；右栏安全渲染 Markdown 正文（剥离原生 HTML）。

  • 侧滑抽屉新建或编辑，带实时字符计数与未保存关闭拦截
  • 新建命中相似标题时抽屉内驻留展示相似条目清单
  • 详情页内置删除确认框，强制填写原因后移入回收站
VIEW 02 · 分类管理

命名空间编排与计数总览

以双列卡片展示全部分类的中文名称、不可变 slug、描述及当前活跃记忆条数。

  • 支持新建自定义分类，工作台胶囊与新建下拉框即时联动
  • 支持就地修改分类名称与描述（CLI 无此编辑命令）
  • 删除非空分类（含回收站残留）时明确报错拦截
VIEW 03 · 凭据管理

权限矩阵分配与生命周期管控

展示全量数据库签发凭据的状态、权限摘要、创建时间与最后调用时间。

  • 支持「全库读写」「全库只读」「按分类自定义无/只读/读写」三种签发模式
  • 签发后弹出单次明文复制对话框；当前登录凭据标记不可操作
  • 有效凭据提供「吊销」，已吊销凭据提供永久「删除」
VIEW 04 · 时效复核

到期记忆聚合与快捷顺延

自动筛选全库已设置 review_at 且早于当前时间的活跃记忆集中展示。

  • 单行提供「延期 +30 天」「延期 +90 天」两个快捷动作
  • 如需改为指定日期或清除复核期，回到工作台编辑抽屉完成
VIEW 05 · 回收站

软删审计查看与一键恢复

按删除时间倒序列出已软删除记忆，完整展示原所属分类、删除日期与当时填写的删除原因。

  • 点击「恢复」立即将条目还原至原分类活跃列表
  • 不提供单条彻底销毁或清空回收站按钮
SHELL · 会话与运行护栏

零持久会话与运维基线

登录凭据仅存于当前浏览器标签页 sessionStorage，关闭标签页即退出，遇 401 自动清空回登录页。

  • 支持浅色 / 深色主题切换（偏好存 localStorage）
  • 备份与回灌不进 Web 界面，由宿主机定时或手动调用 CLI 执行
